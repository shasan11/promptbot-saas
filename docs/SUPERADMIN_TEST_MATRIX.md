# Superadmin Test Matrix

| Module | Core checks |
|---|---|
| Dashboard | Metrics load and links resolve |
| Tenants | Provision, edit domain, change plan, suspend/activate |
| Plans | Create, update, archive restrictions |
| Subscriptions | Filter, update plan/status, cancellation |
| Payments | Create, edit, validate links, settle invoice, refund |
| Invoices | Create totals, configured prefix/tax, payment history, void |
| Tickets | Create, assign, SLA, reply, internal note, status transitions |
| Reports | Date range, currencies, CSV exports |
| Website | Page sections, publishing, navigation, footer, settings |
| Health | Checks, cache clear, retry/forget/flush failed jobs |
| Settings | Partial updates, secrets, mail test, runtime branding |
| Permissions | Owner, auditor, and direct write-route behavior |
