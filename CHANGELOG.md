# Changelog

## 1.0.0 - 2026-08-08

- Initial commercial omnichannel helpdesk release.
- Multi-tenant customer management, channels, unified inbox, tickets, and tasks.
- Queues, deterministic routing, presence, business-hours SLA, and escalations.
- Saved replies, macros, deterministic automation rules, notifications, segments, lists, and import/export.
- Forms, customer portal, public help center, CSAT, reporting, quality, and workforce basics.
- Scoped developer API keys, signed outbound webhooks, audit, retention, privacy, and usage controls.
- Web installer support, tenant provisioning, update command, demo seeding, and deployment documentation.

This product contains no AI-generated reply, classification, summarization, routing, sentiment, or automation behavior.
